# Pawcare — Practo for Animals

Pawcare is a responsive animal healthcare discovery platform prototype.

## Features
- Discover veterinary clinics and pet hospitals.
- Explore pet boarding, diagnostics and animal ambulance services.
- Find animal NGOs and welfare organisations.
- Search by location and service category.
- View provider profiles and save favourites.
- Submit business listings and correction requests.

## Technology Stack
- React
- Vite
- JavaScript
- CSS
- Lucide React

## Demo Notice
This project contains illustrative provider listings and demonstration forms. Provider information is not verified, and form submissions are not transmitted or stored.
